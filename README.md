# ToDo

My very own to-do list, created for my first HackClub Resolutions project!

## Usage

```bash
python main.py "Task"
python main.py -l
python main.py -c ID
python main.py -d ID
python main.py -e ID
python main.py -v
```

Use `-l` to list, `-c` to complete, `-d` to delete, `-e` to edit, and `-v` for the version.
